# Contribute to Minicraft 🚀

Hello! Thank you for your interest in contributing to **Minicraft**. All help is welcome to make this project even better!

Please read this guide before you start contributing.

## 🛠️ How to Get Started

1. Fork this repository.

2. Clone your fork locally:

``bash
git checkout -b my-new-feature

``
3. Create a Branch for your changes:

``bash
git checkout -b my-new-feature

``

## 🐛 Report Bugs or Suggest Features

If you find a bug or have an amazing idea for Minicraft:

1. Check if there is already an open Issue on the same topic.

2. If it doesn't exist, open a new Issue detailing:

* The current behavior (the error).

* The expected behavior.

* Steps to reproduce the problem.

## 💻 Submitting Changes (Pull Requests)

For your code to be accepted by @CuquedoHacker, ensure that:

* The code follows the style and organization of the rest of the project.

* You tested the changes locally and nothing is broken.

* Your commit has a clear and descriptive message.

### Steps for the Pull Request:

1. Push your branch:

``bash

git push origin my-new-feature

``
2. Open a **Pull Request** (PR) against the `main` branch of the original repository.

3. Wait for code review feedback!

## 📜 Code of Conduct

Ensure you maintain a respectful, constructive, and friendly tone with all other members and contributors to the community.
